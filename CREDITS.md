# Credits & Attribution

Agon stands on the shoulders of the open-source fitness / self-tracking ecosystem. This file records
every project whose **ideas, formulas, data, or code** Agon borrows, the license involved, and what
was taken. It is the authoritative attribution ledger; each borrow site in the codebase should also
carry an inline comment pointing back to the relevant entry here.

See `docs/landscape-scan.md` for the full landscape scan and the reasoning behind each choice.

## How to read this file

- **Mode — Reimplemented (idea only):** behavior/strategy reproduced from scratch; **no source
  copied**. Required for copyleft (AGPL/GPL) projects unless Agon itself adopts that license.
- **Mode — Formulas:** mathematical formulas used (not copyrightable); the surrounding project is
  credited as the reference implementation.
- **Mode — Code/dependency:** source copied or the library used directly — only permitted for
  **permissive** licenses (MIT/Apache/BSD), and the original copyright notice is retained.
- **Data:** an openly-licensed dataset is used; attribution follows the data license.

> ⚠️ Licenses below are best-effort reads and **must be confirmed against each repo's `LICENSE`
> before any code is copied.** Projects relicense; dual-licensing exists.

## Licensing policy

- Copy **code** only from **permissive** (MIT/Apache/BSD) projects, retaining their license header.
- From **copyleft** (AGPL/GPL) projects, **reimplement the idea** — copying source would obligate
  Agon to adopt AGPL/GPL (and AGPL additionally requires publishing source to network users).
- Mathematical **formulas** (Banister, Riegel, VDOT, e1RM) are free to use regardless of the
  surrounding project's license; credit the reference implementation.

_When a borrow ships, add its commit/PR and flip the row to **Shipped**._
